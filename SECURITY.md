| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or security bug within this project, please report it responsibly:

- **Email:** Send details to Thomas Sapp at [tpsapp@hotmail.com](mailto:tpsapp@hotmail.com).
- **Details to Include:**
  - Description of the vulnerability and potential impact.
  - Steps to reproduce or proof-of-concept payload.
  - Affected components or functions.

Please do not open a public issue for security vulnerabilities until they have been reviewed and addressed. You will receive an acknowledgment within 48 hours.
